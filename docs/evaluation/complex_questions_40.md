# Набор из 40 сложных вопросов для проверки агентной системы

## Зачем нужен набор

Эти вопросы проверяют не только поиск похожего изделия. Для ответа системе
нужно обращаться к каталогу, остаткам, нормативной матрице, документам и
графу объекта, сохранять конфликтующие факты и объяснять, где требуется
решение эксперта.

Машиночитаемая версия находится в
`data/evaluation/complex_questions_40.jsonl`. В ней для каждого вопроса
указаны необходимые инструменты, источники, обязательные части ответа и
предупреждение, которое нельзя потерять.

## 1. Подбор замены

1. `AQ001` — чем заменить задвижку на участке H2S при нулевом остатке.
2. `AQ002` — поиск аналога отвода 90° 426x10 для H2S с объяснением отклонений.
3. `AQ003` — допустима ли сварная труба вместо бесшовной того же размера.
4. `AQ004` — сравнение 09Г2С, 13ХФА и 09ГСФ для газа с CO2.
5. `AQ005` — замена задвижки PN40 на PN63 с проверкой соседних соединений.

## Правило оценки

Ответ считается полноценным, только если система:

- называет использованные источники;
- не выдаёт синтетические карточки за реальные;
- различает совпадение параметров и доказанную применимость;
- сохраняет конфликтующие значения;
- показывает недостающие документы;
- оставляет окончательное решение эксперту.
