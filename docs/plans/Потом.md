### Нет автоматического формирования заявки на закупку (для эксперта)
Проблема:
Сейчас система только показывает список. Эксперт должен вручную перенести его в систему закупок. Это лишний шаг.

Решение:
Добавить опциональный вывод в формате, готовом для импорта в ERP/1С:

text
1. Создать CSV/JSON с колонками:
   - ksm_code
   - item_type
   - urgency (1–5)
   - urgency_label (критическая / высокая / средняя / низкая)
   - recommended_qty (рассчитать по формуле: min_stock - current_stock)
   - unit (шт / м / кг)
   - source (UNIT-SYN-H2S-001)

2. В ответе добавить поле purchase_order_preview: List[PurchaseOrderItem]
